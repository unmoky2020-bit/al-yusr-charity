> آخر تحديث: 13 نوفمبر 2026. **الصورة الكاملة من الألف للياء في `docs/HANDBOOK.md`، وقواعد الوكلاء في `AGENTS.md`.**

## المشروع
- **الموقع ولوحة التحكم:** React + Vite + TypeScript (الريبو ده)، منشور على `elyusr.org`.
- **الـ API:** Laravel 12 + PHP 8.3 + MySQL على Hostinger Cloud (`api.elyusr.org`). الكود على السيرفر بس، ودخوله ريبو خاص هو أول بند في الخطة.
- **المنشور دلوقتي:** فرع `release/live-2026-11-04`. **main على GitHub** فيه كل شغل 8 نوفمبر، والحزمة الجاهزة للنشر في `backend-handoff/deploy-2026-11-08`. الفولدر اللوكال اتحدّث لنفس النسخة.
- **شغل محمد في `eldakrouryy/alyusr-v2`** (تكريم الإنسان، المشروع الطبي، الحضانات) اتدمج هنا في `f070e57`. من هنا ورايح الشغل كله في الريبو ده بس.

## القواعد
1. أي تعديل يتعمل في الريبو الأول، والنشر بالسكريبت بس. مفيش تعديل بإيد حد على السيرفر.
2. مفيش أرقام ولا نصوص ثابتة في الكود بتظهر للناس. المحتوى من لوحة التحكم.
3. مفيش خدمة بفلوس من غير ما سعرها يبقى معروف.
4. في رمضان وموسم الأضحية مفيش نشر كبير.
5. ممنوع أي باسورد أو بيانات دخول في الشات أو الكود.

## التشغيل
```bash
npm ci && npm run dev                      # http://localhost:8080
npx tsc --noEmit -p tsconfig.app.json      # لازم 0 أخطاء
npm test                                   # 244 اختبار في 57 ملف
```

## نشر الواجهة
1. `bash scripts/deploy/pack-front.sh` → `deploy-out/front-1-assets.tgz` و `deploy-out/front-2-site.tgz`.
2. ارفع **الملفين مع بعض من نفس الفولدر** (بعد ما تتأكد من الـ md5 على جهاز صاحب المشروع)، وعلى السيرفر:
   `rm -rf ~/front-new && mkdir ~/front-new && cd ~/front-new && tar -xzf ~/front-1-assets.tgz && tar -xzf ~/front-2-site.tgz && bash deploy.sh --check && bash deploy.sh`
3. السكريبت بيرفض يبدأ لو الملفين من بناءين مختلفين، وبياخد نسخة احتياطية، ولو التجربة فشلت بيرجّع الصفحة الرئيسية القديمة لوحده. الرجوع اليدوي: `bash ~/backups/front-<التاريخ>/rollback.sh`.

## نشر الباك إند
حزمة في `backend-handoff/deploy-*`: فحص ← نسخة احتياطية ← نشر ← رجوع تلقائي. ومبتكتبش فوق ملف اتغيّر على السيرفر.
