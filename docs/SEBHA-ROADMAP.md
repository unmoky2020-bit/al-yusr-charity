# السبحة: خطة التحسين الجاية والشراكات المقترحة

> مكمّل لـ `docs/SEBHA-REPORT-2026-11-14.md`. ده اقتراح للنقاش، مش التزام.
> **مفيش أرقام متوقعة هنا عمدًا.** أي هدف رقمي يتحدد بعد ما نقيس أول أسبوعين بعد النشر.

## 1) الأول: انشر وقيس
من غير قياس مش هنعرف أي تحسين نفع.
| الحدث (`track`) | ليه |
|---|---|
| `sebha_tap_session` (بداية جلسة عدّ وعددها) | استخدام فعلي، مش مجرد زيارة |
| `sebha_focus_open`، `sebha_undo` | هل الخصائص الجديدة بتتستخدم |
| `misbaha_share` (موجود) + `misbaha_room_created` (موجود) | الانتشار |
| `misbaha_quran_open` (اتضاف) | هل القارئ مفيد |
| رجوع الزائر في اليوم التاني وبعد 7 أيام | المقياس الأهم للعادة اليومية |

- **الأدوات:** GA4 اللي متركّب (`gtag`)، وMicrosoft Clarity لخرائط الضغط وتسجيل الجلسات. Clarity مذكور في الكود، فلازم نتأكد إنه شغال على `/misbaha`.
- **أول اختبار A/B مقترح:** "نوع واحد" ضد "أذكار متنوعة" كوضع افتراضي، ونقيس متوسط عدد الضغطات في الجلسة.

## 2) التحسينات حسب الأولوية

### المرحلة 1: الأسابيع الجاية (أثر عالي ومجهود قليل)
1. **التذكيرات (اتأجلت):**
   - Service Worker + إشعارات Push، والزائر يختار الأوقات بنفسه (بعد الفجر، المغرب، الجمعة).
   - نفس الـ Service Worker يخلّي السبحة تفتح من غير إنترنت.
2. **أذكار الصباح والمساء:**
   - نوع خامس بعدد مختلف لكل ذكر، وعدّاد ينقل للذكر اللي بعده لوحده.
   - المحتوى من "حصن المسلم"، بعد مراجعة المصادر (شوف الشراكات).
3. **تلاوة صوتية في قارئ القرآن:** زرار تشغيل لكل سورة (شوف mp3quran / Quran Foundation تحت).
4. **صفحة "سبحاتي":**
   - رابط ثابت لكل اللي عمله الشخص من سبح مشتركة، محفوظ على الجهاز.
   - يرجعله ويشوف وصلت لفين، وده سبب قوي يرجع.

### المرحلة 2: بعد كده
5. **ختمة جماعية:** نفس فكرة السبحة المشتركة، بس لقراءة القرآن. الأجزاء الـ30 بتتوزع على المشاركين ("خد جزء")، وتنفع لروح متوفى ولرمضان.
6. **ملخص أسبوعي ورسالة "وصلنا للهدف" لصاحب السبحة المشتركة:**
   - البنية موجودة في `mailApi.ts` (`misbaha_weekly`، `misbaha_goal`)، محتاجة تكمّل وتتفعّل.
   - أي إرسال لناس حقيقيين محتاج موافقة صريحة (القاعدة 5).
7. **مزامنة اختيارية بين الأجهزة:** للي عنده حساب على الموقع، عشان الإجمالي والأيام المتتالية مايضيعوش لو غيّر الموبايل.
8. **مواسم:**
   - صفحات مؤقتة في رمضان والعشر الأوائل ويوم عرفة.
   - فيها هدف جماعي على "سبحة جميع المسلمين" (`ummah`)، وعدّاد معروض في الصفحة الرئيسية.

### المرحلة 3: التوسع
9. **تطبيق على Google Play:** نغلّف الـ PWA كتطبيق (TWA). نفس الكود ومن غير تطبيق منفصل.
10. **لغات أكتر:** الإنجليزي موجود. الأولوية بعده للفرنسي والإندونيسي/الماليزي لو الزيارات من بره زادت.
11. **ويدجت للمواقع التانية:** سبحة صغيرة تتحط في مواقع المساجد والجمعيات، مكتوب عليها "من مؤسسة اليسر"، ورابطها راجع لينا.

## 3) مواقع وشركات ممكن نربطها
**مفيش ولا جهة من دول شريك حاليًا.** دي جهات معروفة تستاهل نكلّمها أو نستخدم خدماتها، ولازم نراجع شروط كل واحدة قبل الاستخدام.

### أ) محتوى ديني وتقني
| الجهة | هتفيد في إيه | طريقة الربط |
|---|---|---|
| **Quran Foundation (Quran.com)** | المصحف كامل، والتفسير، والتلاوات، وترجمات | API رسمي بتسجيل ومفتاح |
| **mp3quran.net** | تلاوات صوتية لقرّاء كتير | API مجاني |
| **Tanzil** | نص المصحف العثماني (المصدر الحالي) | نسخة ثابتة في `public/quran/`، والترخيص بيشترط ذكر المصدر ومايتعدّلش النص |
| **Aladhan** | مواقيت الصلاة حسب المدينة، عشان تذكير "أذكار بعد الصلاة" في وقتها | API مجاني |
| **الدرر السنية (dorar.net)** | التحقق من درجة الأحاديث المكتوبة تحت فضل كل ذكر | بحث / API الموسوعة الحديثية |

### ب) المصداقية ومراجعة المحتوى
| الجهة | الفايدة |
|---|---|
| **دار الإفتاء المصرية / مركز الأزهر العالمي للفتوى** | مراجعة نصوص الأذكار والأحاديث وفضائلها، وختم "مراجَع" يزوّد ثقة الناس |
| **مساجد المنصورة والدقهلية** | ملصق فيه QR للسبحة و"سبحة جميع المسلمين" جنب المسجد، ووصول محلي مباشر |

### ج) الانتشار والتذكير
| الخدمة | الفايدة | ملاحظة |
|---|---|---|
| **Firebase Cloud Messaging** أو **OneSignal** | إشعارات Push للتذكير | محتاجة Service Worker، وبموافقة الزائر |
| **WhatsApp Business Platform (Meta)** | تذكير يومي أو رسالة "وصلنا للهدف" على واتساب لمن يشترك | محتاجة موافقة صريحة لكل شخص، والرسائل بقوالب معتمدة وليها تكلفة |
| **Telegram Bot** | ورد يومي ورابط السبحة، ببلاش | جمهور أصغر بس تكلفته صفر |
| **Google Play (TWA عن طريق Bubblewrap / PWABuilder)** | وجود في المتجر | حساب مطوّر برسوم مرة واحدة |

### د) الأثر الخيري (ربط الذكر بالعطاء)
- **الدفع:** موجود بالفعل (Kashier، وInstaPay، وPaymob، وفودافون كاش، وفوري)، ومش محتاجين مزوّد جديد. المطلوب بس زرار "صدقة بنية صاحب السبحة" بمبلغ صغير جاهز، باستخدام نفس طرق الدفع.
- **حملات مشتركة في المواسم مع جمعيات كبيرة** (زي بنك الطعام المصري، ومصر الخير، ورسالة): هدف ذكر جماعي + هدف تبرع. ده محتاج تواصل واتفاق رسمي، ومش موجود حاليًا.

## 4) مخاطر نخلّي بالنا منها
- **المحتوى الديني:** أي ذكر أو حديث جديد يتكتب بمصدره ودرجته، ويُفضّل يتراجع قبل النشر.
- **الخصوصية:**
  - صفحات السبح المشتركة فيها أسماء ناس، وهي `noindex` ولازم تفضل كده.
  - التذكيرات والرسائل باشتراك صريح بس.
- **الاعتماد على خدمات برّه:** أي API ليه بديل، أو نسخة محفوظة عندنا زي ما اتعمل في نص القرآن، عشان السبحة ماتقعش لو الخدمة وقفت.
