## 3. البنية
- **الواجهة:** React 18 + Vite 5 + TypeScript + Tailwind + TanStack Query، اختبارات vitest. كل الصفحات SPA، و`public/seo.php` بيخدم كل رابط بعنوانه ووصفه وcanonical وhreflang (العربي أساسي، الإنجليزي `?lang=en`)، و`/en` و`/ar` بيتحولوا 301، والروابط المجهولة 404.
- **الـ API:** Laravel 12 + PHP 8.3 + MySQL على Hostinger Cloud. الـ queue = `database`، و**مفيش Cron** لحد دلوقتي.
- **السايت ماب:** `sitemap.php` (مباشر من الـ API، كاش 30 دقيقة) فوق `sitemap-base.xml`.
- **المحتوى:** من اللوحة. النص الثابت في الكود احتياطي بيظهر لو الـ API وقع (القرار 1 و2).

## 6. البريد الإلكتروني
| | |
|---|---|
| الخطة | Starter Business Email (تجربة مجانية، تنتهي 2027-11-13) |
| الصناديق | `info@` (الإرسال من الموقع) و`support@` (الردود، Reply-To). المتاح 10 صناديق، المستخدم 2 |
| **حد الإرسال** | **100 رسالة / 24 ساعة لكل صندوق**، 100 مستلم في الرسالة، مرفقات حتى 25MB، 1GB تخزين |
| DNS | SPF وDKIM وDMARC وMX متضبطين (hPanel ← إعدادات الدومين) |
| الإرسال من الموقع | SMTP `smtp.hostinger.com:465`، اتضبط بـ `~/mail-setup.sh` (صاحب المشروع بيكتب الباسورد) |
| اللي بيتبعت دلوقتي | رمز تأكيد البريد، رمز استعادة كلمة المرور (6 أرقام، 15 دقيقة، 5 محاولات). بقالب المؤسسة (`BrandMail`) |
| النشرة | جداول `newsletter_subscribers` (6) و`newsletter_campaigns` ومساراتها موجودة. **ممنوع إرسالها من SMTP** بسبب حد الـ100 (القرار 31) |

**إمكانيات Hostinger «بريد وكيل» (Beta) اللي ممكن نستفيد منها:**
- **Webhook `message.received`:** أي رسالة توصل `support@` تبعت إشعار لرابط عندنا ← ينفع تبقى «تذكرة دعم» في اللوحة تلقائيًا. (الـ payload فيه from/subject/أول 200 حرف/رابط الرسالة والمرفقات.)
- **API + MCP:** وكيل ذكي يقرا ويلخّص ويرد على صندوق الدعم. التوكن يتعمل من hPanel ويتحط في إعدادات الأداة على جهاز صاحب المشروع، **عمره ما يتكتب في الشات**.
- **قوائم السماح/الحظر** للوارد والصادر.
- **رد تلقائي** على `support@` («استلمنا رسالتك…») من hPanel مباشرة.
