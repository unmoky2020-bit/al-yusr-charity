# نشر 3 نوفمبر 2026 — مكتبة الوسائط

## الجديد
- **مكتبة الوسائط بقت بتعرض كل صور الموقع.** ده بيشمل الفولدرات القديمة: `cases/` و`gallery/` و`programs/`… وكل صورة مكتوب جنبها هي مستخدمة فين، مثلًا: حالة 56، أو برنامج 2، أو معرض الصور.
- **الصورة بتتخزن مرة واحدة بس.** لو حد رفع نفس الصورة تاني، السيرفر بيرجّع النسخة الموجودة ومش بيخزن نسخة جديدة. المقارنة بتتعمل بالحجم وبصمة SHA-256.
- **النسخ المكررة اللي موجودة دلوقتي بتظهر لوحدها،** عشان تتنضف.
- **الحذف بقى نقل للسلة، مش مسح نهائي.** الصورة بتتنقل لـ `storage/app/media-trash/<التاريخ>/` (أو `storage/app/private/media-trash/` على Laravel 11 وأحدث، و`deploy.sh --check` بيطبع المسار الصح). وأي صورة مستخدمة في الموقع **مش بتتحذف أبدًا**.
- **الملفات الخاصة مش بتظهر خالص.** يعني الإيصالات والمستندات وأي ملفات مرتبطة بالتبرعات.
- **مسار جديد:** `GET /api/v1/media/find?size=&sha256=`. بيرد بالصورة لو متخزنة قبل كده.
