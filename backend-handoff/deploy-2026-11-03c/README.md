# 3 نوفمبر 2026 (ج) — المدونة

لوحة التحكم بقت بتحفظ المقالات كلها عن طريق `/blog-seo`، اللي بيشيل المقال والسيو مع بعض. قبل كده كانت بتحفظها عن طريق `/content`، وده كان بيرفض رابط صورة الغلاف ("The cover image field must be an image") وبيضيّع حقول السيو.

التعديل في `BlogSeoController.php` فيه حاجتين:
- `GET /blog-seo` للزوار بيرجّع المقالات المنشورة بس، وفريق العمل (بعد تسجيل الدخول) بيشوف كل الحالات. وكمان بقى فيه فلتر `?slug=`.
- `POST /blog-seo` لمقال موجود قبل كده في `contents` من غير سجل سيو: بيربطه بالمقال ده بدل ما يعمل مقال تاني بنفس الرابط.

مفيش migration.

```
cd ~/deploy-2026-11-03c && bash deploy.sh --check && bash deploy.sh
```
