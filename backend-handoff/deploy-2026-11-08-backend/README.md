# 8 نوفمبر 2026 — إشعارات المتبرع + روابط البرامج

**إشعارات لحساب المتبرع نفسه** (زي إشعارات الأدمن بالظبط: جوه الموقع + إشعار المتصفح):
- التبرع اتأكد (بقى `paid`) ← «وصل تبرعك، جزاك الله خيرًا» ويفتح صفحة متابعة التبرع.
- الدفع ما كملش (`failed` / `cancelled`) ← «لم يكتمل تبرعك» ومعاه طريقة يكمّل أو يكلمنا.
- اتضاف تحديث على حالة هو دافع لها ← «جديد عن الحالة التي دعمتها»، مرة واحدة لكل حساب.

المتبرع الضيف (اللي ملوش حساب) مش بيوصله حاجة. الحساب بيتعرف من `donors.user_id`، ولو مش موجود من نفس الإيميل.
أي خطأ في الإرسال مش بيوقف التبرع ولا التحديث (`report()` بس).

**روابط البرامج (slug):** لو حد لزق رابط كامل زي `https://elyusr.org/water` بيتحول لـ `water`.
المسموح بس حروف إنجليزي صغيرة وأرقام وشرطة، والرسالة بتقول ده بالعربي لو فيه غلط.

مفيش migration ولا route جديد.

```
cd ~/deploy-2026-11-08-backend && bash deploy.sh --check && bash deploy.sh
```

`--check` بيقارن كل ملف هيتغيّر بالنسخة اللي التعديل مبني عليها (`expected-base.sha256`).
لو حد عدّل الملف على السيرفر بعد كده، النشر بيقف ومش بيكتب فوق شغله.
