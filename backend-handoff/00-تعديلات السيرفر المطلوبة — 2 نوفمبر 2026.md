## 0) الأمان العاجل (قبل أي نشر)

1. **غيّر باسورد SSH** من hPanel ← Advanced ← SSH Access.
2. **استخدم SSH key بدل الباسورد:**
   ```bash
   # على جهازك (PowerShell أو Git Bash)
   ssh-keygen -t ed25519 -C "elyusr-deploy"
   # انسخ محتوى ~/.ssh/id_ed25519.pub وحطه في hPanel ← SSH Access ← SSH Keys
   ```
3. **غيّر مفتاح Kashier السري** من لوحة Kashier، وحط الجديد في `.env` بس:
   ```
   KASHIER_SECRET_KEY=...
   ```
4. **المستودع على GitHub عام**، وفيه كود الباك إند وعنوان السيرفر. خليه **Private** من: GitHub ← Settings ← Danger Zone ← Change visibility.

## 5) فحص الـ webhook بتاع كاشير

ملف `KashierController` مش موجود في المستودع، فمقدرتش أراجعه. شغّل:

```bash
grep -n -i -E 'signature|hash_equals|hash_hmac|amount|currency' \
  app/Http/Controllers/Api/V1/Kashier/KashierController.php
```

المطلوب يكون موجود في `webhook()`:
- حساب التوقيع بـ `hash_hmac('sha256', ...)` ومقارنته بـ `hash_equals`، ولو مش مطابق يرجّع 400 ومن غير ما يغيّر حالة التبرع.
- مقارنة المبلغ والعملة (`EGP`) بالتبرع المسجّل قبل ما يعلّمه «مدفوع».

لو مش موجودين، ابعتلي محتوى الملف وأكتبلك التعديل.

ونفس الكلام على `paymob/callback` لو Paymob لسه مستخدم. ولو مش مستخدم، احذف السطر بتاعه من `routes/api.php`.

## 7) إخفاء نسخة PHP

**الواجهة:** ملف `public/.htaccess` في المشروع اتعدّل، وهيترفع مع البيلد الجاي.

**الـ API:** ضيف السطرين دول في أول `~/domains/api.elyusr.org/public_html/public/.htaccess`:
```apache
<IfModule mod_headers.c>
    Header always unset X-Powered-By
    Header unset X-Powered-By
</IfModule>
```
ولو فيه ملف `php.ini` أو `.user.ini` في نفس المكان، ضيف فيه: `expose_php = Off`

## 9) بعد أسبوع: تفعيل CSP

الـ CSP دلوقتي Report-Only. بعد أسبوع من النشر من غير شكاوى، غيّر في `public/.htaccess`:
```
Header always set Content-Security-Policy-Report-Only "..."
```
إلى:
```
Header always set Content-Security-Policy "..."
```
وضيف `https://scripts.clarity.ms https://www.clarity.ms` لـ `script-src` و `connect-src`، لأن الموقع بيحمّل Microsoft Clarity ومش مكتوب في السياسة.

## 11) النشرة البريدية: الاشتراك كان مقفول على الزوار (عاجل)

**اتأكدت منها على السيرفر الحي:** الموقع كان بيبعت الاشتراك لـ `POST /newsletter`، والمسار ده جوه مجموعة `auth:sanctum` ومحتاج صلاحية `newsletter.create`. فأي زائر بيحاول يشترك بيرجعله `401 Unauthenticated`، يعني **مفيش ولا اشتراك واحد اتسجّل من الموقع**.

| الملف | الدور |
|---|---|
