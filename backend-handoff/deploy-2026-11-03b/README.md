# 3 نوفمبر 2026 (ب) — دمج الصور المكررة

`php artisan media:merge-duplicates` بيلاقي الصور المتطابقة، يعني اللي ليها نفس الحجم ونفس بصمة SHA-256. وبعدين:
1. أي مكان في قاعدة البيانات بيستخدم نسخة مكررة بيتحوّل للنسخة الأصلية. الأصلية هي النسخة اللي في `media/` لو موجودة، ولو مش موجودة يبقى أقدم نسخة. الروابط بتتغيّر في كل أشكالها: الرابط الكامل، `/storage/…`، المسار من غير `storage`، وصيغة JSON.
2. النسخ اللي بقت مش مستخدمة بتتنقل للسلة: `storage/app/private/media-trash/merge-<الوقت>/`. ومع كل دمج بيتحفظ سجل بكل تغيير اسمه `changes.json`، فيه القيمة القديمة والجديدة.
3. الإيصالات والمستندات الخاصة مبيتلمسوش أبدًا.

## التشغيل
```
cd ~/deploy-2026-11-03b
bash deploy.sh            # تجربة: بيعرض اللي هيتغيّر من غير ما يغيّر حاجة
APPLY=1 bash deploy.sh    # تنفيذ (بياخد نسخة احتياطية من قاعدة البيانات الأول)
```
